📚 Reading List App

A clean and modern mobile app to track your personal reading list — built with React Native, Expo & Appwrite.
<img width="657" height="1280" alt="5474570598198481077" src="https://github.com/user-attachments/assets/2bbfafd9-987a-464b-9b1f-5aef2ea4e400" />

✨ Features

📖 Add books with title and author
✅ Mark books as read or unread
🗑️ Delete books from your list
📊 See your reading stats (total, read, unread)
🌙 Full dark mode support
⚡ Real-time sync with Appwrite database
🎨 Clean and modern UI

🚀 Getting Started
Prerequisites

Node.js installed
Expo Go app on your phone


1. Clone the repo
bashgit clone https://github.com/yourusername/reading-list-app.git
cd reading-list-app
2. Install dependencies
bashnpm install

<img width="629" height="1280" alt="5474570598198481081" src="https://github.com/user-attachments/assets/c01cd19d-178b-4a4b-8dd1-df0d239ba431" />
Go to cloud.appwrite.io and create a project
Create a Database
Create a Collection named books
Add these attributes:

AttributeTypeRequiredDefaulttitleString✅—authorString✅—statusString❌unread

Set Permissions → Any (read + write)
<img width="629" height="1280" alt="5474570598198481080" src="https://github.com/user-attachments/assets/dc15731c-0936-44f1-ba95-6c64371a68b4" />

5. Run the app
bashnpx expo start
Open Expo Go on your phone → scan the QR code  done
